## المزايا

- ١٠٠ آية قرآنية كاملة، تشمل الدعاء والتسبيح والحمد والصبر والرجاء، مع اسم السورة ورقم الآية.
- سؤال اختياري عند الفتح: «كيف تشعر اليوم؟». اختر ما يناسبك من الاطمئنان والحزن والقلق والوحدة والشكر والصبر والأمل، أو انتقل إلى جميع الآيات.
- واجهة بعشر لغات: العربية والإنجليزية والأردية والإندونيسية والبنغالية والتركية والفارسية والملايوية والفرنسية والسواحلية.
- ترجمات منشورة لمعاني الآيات بتسع لغات، مع بيانات المترجم أو الجهة الناشرة وإصدار الترجمة وحواشيها.
- عرض العربية وحدها، أو مع الترجمة، أو الترجمة وحدها. تتبع الترجمة لغة الواجهة غير العربية؛ ويمكن اختيار لغتها مستقلة في الواجهة العربية.
- تقسيم النصوص الطويلة إلى صفحات دون حذف كلماتها، مع خيار لقراءة النص الكامل ومصدره، وحجم خط قابل للتعديل بين ٢٨ و٨٠.
- زر مباشر لوضع ليلي شديد الخفوت، إلى جانب الإضاءة العادية والخافتة.
- مفضلة وعداد مستقل لكل ذكر. يتطلب التصفير تأكيدًا ويمكن إلغاؤه. يغلق زر الرجوع النوافذ المفتوحة والإعدادات قبل مغادرة التطبيق.

تتوفر الأذكار العشرون من الإصدار السابق في أرشيف عربي مع مراجع مفصلة وتمييز المقتطفات. الترجمات التسع مخصصة للآيات القرآنية المائة، ولا تشمل هذا الأرشيف.

## التثبيت والتحديث

نزّل ملف APK وافتحه على شاشة تسمح بتثبيت التطبيقات، ثم اتبع تعليمات نظامها. تختلف قيود التثبيت وإمكانية تفعيل شاشة توقف أندرويد باختلاف الشاشة وبرمجياتها.

يستخدم الإصدار 1.1.0 معرّف التطبيق `com.tariq.dhikr` ومفتاح التوقيع نفسه المستخدم في الإصدار 1.0.0 المنشور. ثبّت التحديث فوق النسخة السابقة للحفاظ على بياناتها. تُحفظ العدادات وتُربط المفضلة القرآنية القديمة بالآيات الكاملة المقابلة. النسخ التجريبية الموقّعة بمفتاح مختلف قد تتطلب إزالتها أولًا، مما يحذف بياناتها المحلية.

اضبط الخيارات أثناء توقف المركبة. لا يتصل التطبيق بأنظمة السيارة ولا يبدأ تلقائيًا عند تشغيلها. التطبيق مستقل وغير تابع لشركة BYD. لم يُختبر هذا الإصدار على شاشة BYD فعلية أو محاكي أندرويد؛ توضح [وثيقة الفحوصات](VERIFICATION.md) ما تم التحقق منه وحدود التوافق.

## المحتوى والخصوصية

النصوص القرآنية وترجمات معانيها من QuranEnc.com. تُحفظ نصوص الترجمة وحواشيها مع نسبتها إلى مصادرها، وتتوفر البيانات كاملة في «النص والمصدر». تُعرض ترجمة المعاني بتمييز واضح عن النص القرآني العربي.

قوائم المشاعر اختيارات موضوعية معدّة مسبقًا لتسهيل الوصول إلى الآيات، ولا تعِد بنتيجة نفسية محددة. اختيار الشعور مؤقت للجلسة ولا يُحفظ له سجل.

لا يتضمن التطبيق إعلانات أو حسابات أو تحليلات استخدام، ولا يطلب إذن الاتصال بالإنترنت. تُحفظ الإعدادات والمفضلة والعدادات في مساحة التطبيق الخاصة، والنسخ الاحتياطي النظامي معطل. لا يطلب صلاحيات الموقع أو الميكروفون أو التخزين العام أو التحكم بالمركبة أو الظهور فوق التطبيقات.

## بناء المشروع

بعد فك حزمة المصدر، افتح مجلد المشروع. المتطلبات: JDK 17 وAndroid SDK 35 وNode.js 22.

```sh
npm ci
npm test
./gradlew assembleDebug lintDebug
```

تبعيات Node.js مخصصة للاختبارات. لبناء إصدار موقّع، اضبط `TARIQ_KEYSTORE_PATH` و`TARIQ_KEYSTORE_PASSWORD` في بيئة البناء، ثم شغّل `./gradlew assembleRelease`. الاسم المستعار للمفتاح `tariq-dhikr`. المفاتيح وكلمات المرور غير مضمنة. توضح وثيقة الفحوصات طريقة بناء ملف APK المرفق؛ ولا تعني الأوامر أعلاه أن جميع فحوصات Gradle أُنجزت في بيئة الإصدار.

## English

Tariq Dhikr is an offline Android app for displaying Quran verses and adhkar on a black background, with a quiet interface and adjustable text. It is designed with large BYD head-unit screens in mind. The head unit must allow APK installation.

**Version 1.1.0 · Build 110 · Android 6.0 or later**

### Downloads

- [Download the APK — version 1.1.0](Tariq-Dhikr-v1.1.0.apk?raw=true)
- [Download the complete Android project](Tariq-Dhikr-v1.1.0-source.zip?raw=true)
- [SHA-256 checksums](SHA256SUMS)

The APK and source archive are distributed through the [app repository](https://github.com/Tariq919/Tariq-Dhikr-BYD). Check the version in each filename before downloading. The source archive contains the Android project, tests and build instructions.

### Features

- 100 complete Quran verses covering supplication, praise, patience and hope, with surah names and verse numbers.
- An optional “How do you feel today?” question at startup. Choose peace, sadness, worry, loneliness, gratitude, patience or hope, or continue to all verses.
- Ten interface languages: Arabic, English, Urdu, Indonesian, Bengali, Turkish, Persian, Malay, French and Swahili.
- Published translations of Quran meanings in nine languages, including translator or publisher details, edition numbers and translator notes.
- Arabic, translation, or combined display. Non-Arabic interfaces use the corresponding translation; the Arabic interface allows a separate translation-language choice.
- Long passages split into pages without dropping words, adjustable font sizes from 28 to 80, and a separate view for the complete text and source.
- A one-touch, very dim night mode, plus normal and dim text levels.
- Favorites and individual counters. Resetting requires confirmation and can be cancelled. Android Back closes open dialogs and settings before leaving the app.

The 20 traditional adhkar from the previous version remain in an Arabic archive with detailed references and excerpt labels. The nine translations cover the 100 Quran verses; they do not cover this archive.

### Installation and updates

Download and open the APK on a head unit that allows app installation, then follow its prompts. Installation restrictions and Android screensaver availability depend on the head unit and its firmware.

Version 1.1.0 uses the same package ID, `com.tariq.dhikr`, and release signing key as the published version 1.0.0. Install it over that release to retain local data. Counters are preserved, and earlier Quran favorites are linked to the corresponding complete verses. A test build signed with a different key may need to be uninstalled first, which removes its local data.

Adjust settings while parked. The app does not connect to vehicle systems or start automatically with the vehicle. It is independent and is not affiliated with BYD. This release has not been tested on a physical BYD head unit or an Android emulator. See [verification and limitations](VERIFICATION.md) for the checks performed.

### Content and privacy

Quran text and published translations of its meanings are sourced from QuranEnc.com. Translation wording, notes and attribution are retained. Full details are available through “Full text and source”. Translations of meanings are clearly distinguished from the Arabic Quran text.

The feeling-based lists are predefined topic selections that help readers find relevant verses. They do not promise a particular emotional outcome. A selection lasts only for the current session; no mood history is stored.

The app has no ads, accounts, analytics or Internet permission. Settings, favorites and counters are stored in private app storage, with system backup disabled. It requests no location, microphone, shared-storage, vehicle or overlay permissions.

### Building from source

Extract the archive and open the project folder. Use JDK 17, Android SDK 35 and Node.js 22, then run the commands above. Node.js dependencies are used only for tests. For a signed release, set `TARIQ_KEYSTORE_PATH` and `TARIQ_KEYSTORE_PASSWORD`, then run `./gradlew assembleRelease`; the key alias is `tariq-dhikr`. Signing keys and passwords are not included. The verification document records how the distributed APK was built and checked; the build instructions are not a claim that a complete Gradle validation was performed for this release.
