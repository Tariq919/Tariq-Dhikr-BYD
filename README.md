# طارق للأذكار · Tariq Dhikr BYD

تطبيق أندرويد مستقل لعرض الأدعية والتسبيحات على شاشات BYD التي تسمح بتثبيت تطبيقات أندرويد. خلفية سوداء بالكامل، نص عربي واضح، ويعمل دون إنترنت أو إعلانات أو صوت.

## المزايا

- ٣٤ نصًا: ٢٢ دعاءً و١٢ ذكرًا وتسبيحًا مع مراجع مختصرة.
- دعاء أو ذكر واحد في المنتصف مع التبديل التلقائي والإيقاف والاستئناف.
- خط كبير قابل للتعديل، وإضاءة نص خافتة، وأزرار تختفي تلقائيًا.
- اختيار الأدعية أو الأذكار أو المفضلة.
- عداد تسبيح يدوي مستقل لكل ذكر يحفظ محليًا؛ التبديل التلقائي لا يحتسب تسبيحات.
- دعم العرض الأفقي والعمودي.
- شاشة توقف أندرويد اختيارية إذا أتاح نظام السيارة اختيارها.

## التثبيت والتوافق

الحد الأدنى Android 6.0 / API 23. نزّل APK وانقله إلى الشاشة بالطريقة التي يسمح بها نظامها، ثم ثبته وافتح «طارق للأذكار» من قائمة التطبيقات.

ملف الإصدار موقع بمفتاح إصدار ثابت خاص؛ لا توجد مفاتيح توقيع أو كلمات مرور داخل هذا المستودع. رقم البناء 2. إذا ثبّتت النسخة التجريبية القديمة الموقعة بمفتاح debug، فقد يلزم حذفها قبل تثبيت هذا الإصدار لاختلاف التوقيع؛ حذفها يمسح إعداداتها وعداداتها المحلية.

تم التحقق من بناء APK وتوقيعه واجتازت اختبارات المنطق السبعة. لم يُختبر التطبيق على شاشة BYD فعلية أو محاكي أندرويد. قد تفرض بعض إصدارات DiLink قيودًا على تثبيت APK، كما يختلف دعم شاشة التوقف حسب النظام. اضبط الخيارات وأنت متوقف.

## الخصوصية

لا إنترنت، ولا حسابات، ولا تحليلات، ولا صلاحيات سيارة أو موقع أو ميكروفون أو ظهور فوق التطبيقات. الإعدادات والمفضلة والعدادات محفوظة على الجهاز فقط. لا يبدأ مع السيارة تلقائيًا ولا يغطي الملاحة أو الكاميرات.

## المصدر والبناء

مشروع Gradle الكامل داخل `Tariq-Dhikr-v1.0.0-source.zip`. فك ضغطه، ثم افتح مجلد `tariq-dhikr-byd` في Android Studio. الواجهة والكتالوج مضمنان محليًا داخل التطبيق.

لبناء المشروع من المصدر تحتاج إلى JDK 17 وAndroid SDK 35. أوامر الفحص والبناء بعد فك الضغط:

```sh
node --test tests/core.test.cjs
./gradlew assembleDebug lintDebug
```

لإنتاج تحديث موقع بمفتاح الإصدار نفسه، اضبط متغيري البيئة `TARIQ_KEYSTORE_PATH` و`TARIQ_KEYSTORE_PASSWORD` ثم شغّل `./gradlew assembleRelease`. اسم المفتاح `tariq-dhikr`. المفتاح الخاص محفوظ منفصلًا ولا يُنشر مع المصدر.

تطبيق مستقل غير تابع لشركة BYD أو معتمد منها؛ يُستخدم الاسم لتوضيح الشاشة المستهدفة.
