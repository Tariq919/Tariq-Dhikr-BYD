# سجل التغييرات | Changelog

## 1.1.0 — 2026-10-26

### العربية

- تأكيد تصفير العداد وإمكانية إلغائه، مع تصفير العداد المحدد وحده.
- إغلاق النوافذ والإعدادات بزر الرجوع قبل الخروج.
- تحسين دعم إصدارات WebView القديمة وإضافة خطوط عربية وبنغالية مضمنة.
- تقسيم النصوص الطويلة مع الاحتفاظ بالنص الكامل والحواشي.
- وضع ليلي شديد الخفوت بزر مباشر.
- سؤال اختياري عن الشعور عند الفتح، دون حفظ سجل للمشاعر.
- ١٠٠ آية كاملة وتسع ترجمات منشورة لمعانيها، وواجهة بعشر لغات.
- حفظ العدادات والمفضلة السابقة وإبقاء الأذكار المأثورة في أرشيف عربي.
- الإبقاء على معرّف الحزمة وشهادة توقيع الإصدار 1.0.0، مع رفع رقم البناء إلى 110.

### English

- In-app reset confirmation and cancellation; only the selected counter is reset.
- Android system Back closes confirmation, details or settings before leaving the app; modern and legacy Back paths are supported.
- ES5-compatible app code without NodeList.forEach or CSS custom-property dependencies; bundled Arabic and Bengali fonts; visible startup/load-error fallback.
- Long texts are paginated at the chosen readable size instead of shrinking below the selected size. Full text and translation notes remain available.
- One-touch very dim night mode, normal and dim text levels.
- Optional, skippable session-only “How are you feeling?” selector with seven curated Quran topic lists. No mood history is stored.
- 100 complete Quran verses with nine unmodified QuranEnc translations of meanings. Ten interface languages, independent text directions, optional Arabic/translation/combined view and translation-language selection for Arabic UI.
- Existing favorites and counters migrate; traditional entries remain in a clearly labelled Arabic archive.
- Same package ID and release signing certificate as version 1.0.0; version code 110.
